# RetailPulse — E-Commerce Analytics & Business Intelligence

> End-to-end analytics project focused on transforming relational e-commerce data into actionable business insights.
>
> ## Overview

RetailPulse is an end-to-end e-commerce analytics project that integrates multiple relational datasets to analyze sales, customers, products, and overall business performance.

## Project Objectives

- Integrate and prepare relational e-commerce data for analysis
- Perform data cleaning and validation
- Analyze key sales and customer KPIs
- Identify high-value customers using RFM analysis
- Classify products using ABC analysis
- Examine revenue concentration using Pareto analysis
- Develop business-focused reporting using SQL and Power BI

## Dataset Overview

The project uses 8 relational e-commerce datasets covering key business areas such as customers, orders, products, payments, shipments, suppliers, and reviews.

Key reported figures:

- **20,000** unified records
- **15,000** orders
- **10,000** customers
- **$56.8M** total revenue

## Analytical Approach

The project follows a structured analytics workflow:

**Data Integration → Data Cleaning & Validation → Exploratory Data Analysis → KPI Analysis → Customer & Product Analytics → Business Intelligence**

## Key Analysis

### Customer Analytics
RFM analysis is used to evaluate customers based on:

- **Recency** — How recently they purchased
- **Frequency** — How often they purchased
- **Monetary Value** — How much they spent

### Product Analytics
ABC analysis is used to classify products according to their contribution to overall revenue.

### Revenue Concentration
Pareto analysis identified **1,247 products** and **5,064 customers** associated with the reported 80% revenue concentration.
